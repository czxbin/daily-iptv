# 每日直播源设计

按用户请求：每天刷新公开 IPTV 社区目录，分类央视、卫视、港澳台及海外频道，验证后输出 VLC 可导入的 UTF-8 M3U，并通过 GitHub 固定地址发布。

实现选择：Python 3.12 标准库、FFmpeg、GitHub Actions，每日北京时间 06:23（UTC 22:23）。公开仓库和固定 raw 地址已获用户批准。无付费服务、无代理、无绕过 DRM 或地域限制。

只对公开 HTTP(S) 地址有限读取；过滤本地和私有 IP，拒绝认证 URL 和不透明链接修饰符。递归读取 HLS 后下载有限媒体数据，在本地用 FFmpeg 实际解出视频帧；只收到 HTTP 200 或清单不算成功。检测来自 GitHub 执行器，不保证用户网络可播。

每日候选有界、按日期轮转、每频道最多两个变体，保留来源、区域、授权状态（社区源未知）和结果。只发布本次通过解码的列表；全部失败、来源拉取大范围失败或频道数骤降时保留上一份有效列表并标为过期。报告保留最近 30 次运行，不保存媒体数据。

替代方案：私库 raw 需要认证不适合直接 VLC；Pages 需额外配置；因此选择 raw URL。
